## 📋 最近更新
 
### 📅 2026-05-12 开发总结

**今日核心进展**：
- 基于策划案确认建造系统定位：建造是营地阶段对“明日牌库/回合收益”的扩展与控制系统，而不是自由摆放建筑系统。
- 营地界面新增“建造”页签，支持已建造/未建造两级页签。
- 未建造建筑按等级与类型分组，卡牌横向排列同类型、竖向排列不同类型，并按材料满足状态排序。
- 建筑卡片精简为建筑名、图片、材料图片+数量和建造天数；详细说明改为鼠标悬浮详情面板展示。
- 点击可建造建筑后弹出二次确认窗口，展示建筑图片、建筑名和材料图片+数量；确认后消耗材料并进入建造中状态。
- 已建造页签区分工作建筑与增强建筑，建造中的建筑显示剩余天数，完成后才生效。

**主要修改模块**：
- 营地建造 UI：新增建造页签、建筑列表、建筑卡牌、悬浮详情与二次确认窗口。
- 建造数据与流程：新增建筑配置样例、材料满足检测、建造消耗、建造倒计时和建成生效状态。
- 材料展示：建筑卡片和确认窗口统一使用材料图标徽章，并将已满足材料排在前面。

**待解决问题**：
- 当前建筑目录仍使用脚本内测试数据，后续需要接入正式配置表。
- 建筑收益与增强效果目前只完成 UI 和状态链路，后续需要接入正式回合结算。

#### [17:50] 营地建造系统 - 新增
**需求描述**：在营地界面新增建造入口，让玩家能按建筑类型查看已建造/未建造建筑，并消耗材料启动建造。

**开发内容**：
- 顶部模式页签新增 `建造`，切换后进入营地建造界面。
- 建造界面新增 `已建造` 和 `未建造` 两个子页签。
- `已建造` 页签按“工作建筑”和“增强建筑”分区展示；工作建筑用于每回合提供收益，增强建筑用于建成后一次性增强。
- `未建造` 页签按建筑等级与类型分组，同一类型建筑横向排列，不同类型分组竖向排列。
- 新增建筑测试目录，包含食物制造间、木材加工厂、气象塔、地质仪、观测牌桌等建筑数据。
- 未建造建筑根据是否满足材料需求排序；满足材料的建筑会高亮为绿色并排在分类前方。
- 建筑卡片显示建筑名、建筑图片、所需材料图标与数量、建造天数。
- 建筑详细说明、类型、效果、完整材料需求等信息移入鼠标悬浮详情面板，复用物品详情展示逻辑。
- 点击满足材料的建筑卡片会弹出二次确认窗口，确认后扣除对应材料并开始建造。
- 建造中的建筑会出现在已建造页签中，显示“建造中：剩余 X 天”，建造完成后才进入生效状态。
- 进入下一天时推进建造倒计时，剩余天数归零后标记建筑生效。

**开发方式**：
- 建造界面当前在 `CraftingWorkbenchUI.gd` 中动态生成，优先复用现有营地 UI、背包材料统计和物品悬浮详情链路。
- 建筑数据暂放脚本内测试目录，后续可替换为配置表驱动。

**涉及文件**：
- `script/HUD/CraftingWorkbenchUI.gd`（新增）
- `.trae/rules/project-rv-diary.md`（更新）

## 📌 开发规范提醒

### 节点引用规范
- ✅ 内部固定节点：使用 `@onready var node: Type = $NodePath`
- ✅ 外部动态实体：使用 Group 或全局单例
- ❌ 禁止：`get_node("String")` 魔法字符串
- ❌ 禁止：跨实体微观操纵（如 `player.get_node("Stats")`）

### 注释规范
- 变量：行末 `#` 注释
- `@export` 变量：上方 `##` 文档注释 + 行末 `#` 注释
- 方法：`func` 上方 `#` 功能注释，且必须使用中文说明方法实现什么功能

### 代码分区
- `#region 1. 暴露的配置参数`
- `#region 2. 内部状态数据`
- `#region 3. 生命周期与核心逻辑`
- `#region 4. 辅助方法`
