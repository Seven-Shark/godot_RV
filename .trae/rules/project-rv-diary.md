#### [12:05] 敌人追踪防卡死绕行 - 优化
**需求描述**：解决敌人追踪目标时被 WorldEntity 大体积障碍阻挡后无法绕行的问题。

**开发内容**：
- 在通用导航移动中加入“卡住检测 + 绕行恢复”机制。
- 将绕行触发条件收紧为“位移不足 + 前方真实阻挡”，避免正常移动抖动。
- 增加自适应绕行：多档侧向探测距离 + 动态绕行时长，提升大障碍绕行成功率。
- 强制清仇恨时重置导航恢复器状态，避免状态残留。

**开发方式**：
- 通过导航层统一增强，不改状态机主流程；参数化导出便于 Inspector 调优。

**涉及文件**：
- `script/Character/Enemy_state/enemy.gd`（优化）

#### [13:05] 敌人追踪避障策略 - 优化
**需求描述**：让敌人遇到圆形障碍优先“滑行通过”，仅在双侧封堵时执行大圈绕行。

**开发内容**：
- 在导航主循环中加入前向阻挡主动探测，命中障碍时优先生成“切线滑行”速度。
- 基于障碍法线计算双侧切线候选方向，选取未被阻挡的一侧进行滑行，避免顶住抖动。
- 当切线两侧都不可行时，保留并强化“大绕行”策略，扩展多档探测倍率以支持相邻大障碍封堵场景。
- 新增滑行相关导出参数（探测距离、前向混合权重），支持按敌人类型微调表现。

**开发方式**：
- 采用“滑行优先、绕行兜底”的两级导航恢复机制，不改变现有状态机主流程。

**涉及文件**：
- `script/Character/Enemy_state/enemy.gd`（优化）

## 📌 开发规范提醒

### 节点引用规范
- ✅ 内部固定节点：使用 `@onready var node: Type = $NodePath`
- ✅ 外部动态实体：使用 Group 或全局单例
- ❌ 禁止：`get_node("String")` 魔法字符串
- ❌ 禁止：跨实体微观操纵（如 `player.get_node("Stats")`）

### 注释规范
- 变量：行末 `#` 注释
- `@export` 变量：上方 `##` 文档注释 + 行末 `#` 注释
- 方法：`func` 上方 `#` 功能注释

### 代码分区
- `#region 1. 暴露的配置参数`
- `#region 2. 内部状态数据`
- `#region 3. 生命周期与核心逻辑`
- `#region 4. 辅助方法`

### 记录执行规则

1. **实时记录**：每次完成一个开发任务后，立即在「详细修改记录」区域追加一条记录
2. **时间标注**：使用 24 小时制，格式 `[HH:MM]`，如 `[14:30]`
3. **日期分组**：如果是新的一天，先创建新的日期标题（如 `### 2026-04-23`），再追加记录
4. **更新总结**：每日开发结束前，更新「最近更新」区域的每日总结
5. **更新索引**：如有新模块或模块状态变更，同步更新「模块索引」表格
6. **去重原则**：同一天内对同一模块的多次修改，可合并为一条记录，避免碎片化
