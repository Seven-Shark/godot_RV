## 项目定位

当前世界观与核心系统暂定采用“收音机 ERS”设定。

玩家每天白天外出探索、采集、战斗与回收材料；夜晚回到庇护所后，通过一台异常收音机接收“明日播报”，并以赊账购买卡包的方式获得线索元素，使用 ERS 系统对明天的环境进行有限改写。

收音机播报的内容会影响次日地图、物件、资源点、敌人分布与环境风险。玩家无法随意创造明天，只能基于当晚收到的播报与自己拥有的材料，选择削弱、转移或利用其中一部分变化。

当前 ERS 方向进一步确定为“线索元素组合”。玩家不是单纯选择固定播报，而是通过白天获得的线索元素，以及夜晚赊账购买的明日卡包，在夜晚组合出新的明日播报。特定组合可以生成特殊资源环境、特殊地图区域，甚至召出特定 Boss。

## 核心机制

### 场景演化

每天的地图与物件状态会根据夜晚的收音机 ERS 选择发生变化。

收音机 ERS 可以影响的内容包括：

- 次日地图中的资源点分布。
- 次日可交互物件的出现、强化、损坏或消失。
- 特殊事件区域、危险区域或高价值区域的生成。
- 敌人、巢穴、腐化或其他环境压力的分布。
- 庇护所周边或关键路线的安全程度。

场景演化的设计重点不是让玩家完全控制世界，而是让玩家通过有限干预改变明天的生存条件。

场景演化不仅包含资源数量变化，也可以包含区域性质变化。例如玩家将“森林”和“岩浆”两个线索组合后，第二天可以生成“灰烬林”。灰烬林能提供更高效的木材采集机会，但也会带来灼烧地形、食物减少、火焰敌人或 Heat 增加等代价。

类似组合方向包括：

- 地点 + 环境：生成特殊区域，例如灰烬林、迷雾林、黑仓库、冻水渠。
- 地点 + 资源：生成资源富集区，例如富木林、线缆仓库、湿粮点。
- 地点 + 生物：生成怪物活动区、巢穴区或精英怪出没区。
- 地点 + 信号 / 残响：生成主线异常、Boss 前置事件或 Boss 战场。

### 环境重构系统（ERS）

ERS 当前包装为“收音机系统”。

玩家每天晚上回到庇护所后，可以通过收音机接收明日播报，并选择其中一部分内容进行改写。改写结果会在第二天体现为地图与物件变化。

ERS 的核心设计方向是：玩家通过收音机捕获“明日线索”，也可以在夜晚通过赊账提前购买卡包，获得更多用于组合明天的线索元素，再将线索组合成播报。播报会把地图区域改造成特定环境、资源区、怪物事件或 Boss 战场。

收音机 ERS 的基础交互方向：

- 接收明日播报：展示次日可能发生的环境变化。
- 选择播报内容：从有限选项中选择一个主要干预目标。
- 赊账购买卡包：夜晚可提前购买明日卡包，获得用于组合明天的线索元素，并记录为欠款。
- 组合并改写：使用已获得的线索元素组合明日播报，决定次日地图、资源、敌人与风险变化。
- 生成明日状态：根据玩家选择改变次日地图、物件、资源与风险。
- 隔天偿还欠款：次日回到营地后，必须处理前一天欠款，偿还后才能继续赊账。

该系统是夜晚阶段的核心策略入口，也是“今天的收获决定明天怎么活”的主要表达方式。

#### 明日卡包与赊账

玩家每天晚上可以通过赊账的方式提前购买明日卡包。卡包提供用于组合明天的线索元素，让玩家在资源不足时仍然可以主动塑造次日地图，但会把压力转移到隔天的偿还阶段。

赊账规则：

- 每晚进入 ERS 阶段时，玩家可以选择赊账购买卡包，用卡包内容组合明日地图。
- 购买卡包不会立刻扣除足额资源，而是生成一笔欠款，记录到次日。
- 隔天玩家回到 `HomeScene` 后，需要先偿还前一天欠款，才可以继续进行新的赊账购买。
- 如果玩家无法或不愿立刻偿还，可以选择延期偿还。
- 最多允许延期偿还 3 次。
- 如果同一笔欠款已经延期 3 次后仍未偿还，则视为游戏失败。

该规则的设计目标是让 ERS 选择从“我现在买不买得起”变成“我敢不敢透支明天”。卡包购买不只是抽取奖励，而是一次风险承诺：今天提前拿到组合能力，明天必须用探索收益偿还。

需要避免的实现方向：

- 不要让赊账只变成免费的延迟扣款，否则玩家会默认每晚赊账，失去决策压力。
- 不要把延期次数隐藏在后台，玩家必须清楚看到当前欠款、已延期次数、剩余可延期次数和失败风险。
- 不要让失败只因为玩家忘记还款触发，进入下一次赊账或延期前必须有明确确认。

#### 线索元素组合

线索元素是 ERS 的基础组合材料。玩家可以通过猎杀怪物、探索地图、采集特殊物件、推进主线或赊账购买明日卡包获得线索元素。

线索元素暂定分为以下类型：

- 地点元素：森林、废仓库、水渠、广播塔、矿坑、庇护所周边。
- 环境元素：雨、雾、岩浆、灰烬、腐化、停电、强风。
- 资源元素：木材、铁片、铜线、磁带、食物、怪物残骸。
- 生物元素：游荡者、听觉者、巢群、精英怪、Boss。
- 信号元素：残响、校时、回波、静默、异常播报。
- 代价元素：Heat 增加、Blight 增加、Nest 增加、Stability 下降、夜晚强化。

组合结果示例：

- 森林 + 岩浆 = 灰烬林。
- 森林 + 岩浆 + 木材 = 灰烬林中出现大量炭化木材，采集更快，但环境伤害与 Heat 增加。
- 废仓库 + 铜线 = 线缆仓库，铜线资源增加，但开箱噪音或伏击风险增加。
- 广播塔 + 残响 = 回波塔，次日可获得额外线索，但 Heat 增加。
- 广播塔 + 校时 + 残响 = 召出或推进“报时者”相关 Boss 事件。

Boss 也可以通过特定线索组合生成或塑造。玩家可以根据准备情况主动触发 Boss，而不是被固定日期强制遭遇。主线 Boss 组合需要有明确提示，避免玩家误触发或卡进度；隐藏变体组合可以改变 Boss 战场、机制或掉落奖励。

Boss 组合示例：

- 广播塔 + 校时 + 残响 = 标准报时者。
- 森林 + 校时 + 残响 = 林间报时者，场地障碍更多，但木材奖励更高。
- 废仓库 + 校时 + 残响 = 仓库报时者，零件奖励更多，但伏击风险更高。
- 灰烬林 + 校时 + 残响 = 灰烬报时者，火焰危险更高，但可掉落稀有炭化核心。

组合系统需要提供结果预览与 Boss 触发确认。高收益组合必须伴随明确代价，避免形成无脑最优解。

### 生存与资源循环

当前循环方向：

- 白天怪物会少量生成，玩家可以通过猎杀变异怪物获得资源与“残响”类货币。
- 白天地图上的其他资源点用于采集基础材料，支持设施升级、工具合成和角色强化。
- 夜晚外部怪物数量更多且强度更高，原则上不鼓励玩家继续探索，而是推动玩家回到庇护所进入夜晚策略阶段。
- 玩家晚上可以通过赊账购买明日卡包，获得新的线索元素，并使用线索组合改变第二天的地图、物件、资源点、敌人或 Boss 条件。
- 隔天探索收益不仅用于成长和设施，也用于偿还前一天卡包欠款；如果玩家持续延期偿还，最多 3 次后会触发游戏失败。

怪物掉落与资源点职责暂定区分如下：

- 怪物掉落：残响、怪物材料、特殊合成件，用于驱动收音机、解锁线索、偿还欠款、制作战斗或 ERS 工具。
- 地图资源点：木材、铁片、铜线、破布、食物、草药、电池等，用于设施升级、基础工具、恢复与长期生存保障。

该循环的设计目标是让玩家同时拥有三类白天目标：猎杀怪物以推动明日改写，采集资源以提升自身和庇护所能力，回收足够收益偿还前一晚的卡包欠款。

### 建造与设施

建造系统当前定位为“明日牌库的扩展与控制系统”，而不是传统生存游戏中自由摆放建筑、扩张基地面积的系统。

玩家通过建造设施，主动把新的天气、地形、生物、信号、资源和末日前兆牌加入明日牌库；同时，部分设施提供查看、锁定、弃置、诱导或保留明日牌的能力。建筑的核心价值不是单纯提供数值收益，而是改变玩家未来会遇到什么、能控制多少、敢承担多大的风险。

#### 设施的两类职责

1. 牌库扩展设施：负责把新牌加入明日牌库，让游戏内容随进程变得更丰富、更危险、收益更高。
2. 牌库控制设施：负责让玩家在更复杂的牌库中做有限干预，降低纯随机感，形成“我建了什么，所以我能处理什么”的成长反馈。

扩展设施和控制设施必须成对设计。如果只有扩展设施，玩家会觉得建造是在让游戏变难；如果只有控制设施，牌库不会成长，长期体验会变平。合理结构是：玩家先被基础牌库限制收益，然后通过建造扩展牌库获得更高收益机会，再通过控制设施把风险变成可规划挑战。

#### 牌库扩展设施示例

- 气象塔：将雷雨、浓雾、强风、暴雪等天气牌加入牌库。雷雨可以配合森林或导电装置产生自动伐木、范围伤害等连锁收益，但也会提高火灾、受击、视野受限等风险。
- 地质仪：将火山、塌方、裂隙、矿脉暴露等地形牌加入牌库。用于解锁高价值矿物与环境杀伤，但会带来路线阻断、持续伤害和撤离压力。
- 广播接收器：将回波、静默、校时、异常播报等信号牌加入牌库。用于推进 ERS、Boss 前置事件和末日前兆，但会提高系统反制和异常事件概率。
- 生态笼 / 兽栏：将狼群、巢群、听觉者、精英怪等生物牌加入牌库。用于获取怪物材料、赏金和特殊掉落，但会显著提升战斗压力。
- 黑市联络站：将高价交易品、危险合约、稀有元素、污染交易等经济牌加入牌库。用于快速获得金钱或稀有元素，但会提高债务、末日进度或地图惩罚。

#### 牌库控制设施示例

- 观测牌桌：每天可以查看一张盖着的明日牌类型，帮助玩家判断是否继续翻牌。
- 锁牌台：允许玩家锁定一张已揭示的明日牌，使其不会被刷新或替换。
- 弃牌槽：每天可以弃置一张已识别的风险牌，但弃置应有成本，避免变成无脑删除风险。
- 元素调谐器：提高某一类牌的出现权重，例如天气、资源、生物或信号，但不能保证必出。
- 预言钟：显示当前明日牌列中风险牌的数量，不直接告诉玩家具体牌面。
- 档案柜：允许玩家保留一张未使用的已揭示牌到下一天，形成跨日规划。

#### 解锁节奏

建筑推进应承担牌库成长节奏，而不是完全依赖天数硬提升难度。

- 第一阶段：基础营地设施。工作台、储粮仓、交易柜台等设施用于支撑基础生存、资源处理和明日翻牌。
- 第二阶段：牌库扩展设施。气象塔、地质仪、广播接收器等设施开始向牌库加入新类别，让玩家获得更高收益和更明确的环境组合目标。
- 第三阶段：牌库控制设施。观测牌桌、锁牌台、弃牌槽、元素调谐器等设施让玩家在复杂牌库中建立可学习的控制策略。
- 第四阶段：末日准备设施。末日观测仪、反制装置、终局地图构筑台等设施用于识别、压制或主动触发末日相关牌。

#### 设计约束

- 每个扩展设施都必须同时带来机会和麻烦，不能只解锁收益牌。
- 每个高风险牌库扩展都应配套至少一种应对路径，例如装备、设施、任务、道具或局内环境利用方式。
- 建筑不能只做加成数值。数值收益可以存在，但核心功能必须改变牌库、翻牌决策或地图执行策略。
- 不应允许玩家无限拖延牌库扩展。低级牌库的收益要逐步不足以支撑租金、饱食度、末日准备或主线任务，迫使玩家主动扩大牌库。
- 扩展牌库时必须让玩家明确知道“新加入了什么类型的牌”和“大概会带来什么风险”，避免难度提升变成暗箱惩罚。

## 游戏流程

阶段推进应围绕“玩家如何逐步掌握并扩大 ERS 组合能力”设计。

第一阶段目标是让玩家理解基础循环：白天猎杀与采集，夜晚通过收音机和赊账卡包获得线索，并用简单组合改变第二天地图；隔天回营地后偿还前一晚欠款，再决定是否继续透支。第一阶段 Boss 可以作为基础考试，要求玩家使用特定线索组合主动生成或推进 Boss 事件。

第二阶段应在第一阶段基础上提供新体验：开放更复杂的线索组合，让玩家从“选择明天”进阶到“拼装明天”。难度提升不应只依靠怪物数值，而应增加规划压力、资源压力、区域代价与组合副作用。

阶段体验方向：

- 第一阶段：收音机启用，玩家学会明日播报会改变地图。
- 第二阶段：线索组合展开，玩家学会主动设计资源区、危险区和 Boss 前置条件。
- 第三阶段：广播反噬，电台开始识别玩家，玩家的改写行为会被系统反制或产生长期后果。

## 玩家成长

玩家成长由三条线组成：角色 / 装备成长、营地设施成长、明日牌库成长。

角色和装备成长解决“我进地图后能不能执行计划”；营地设施成长解决“我能不能处理资源、食物、租金和明日牌”；明日牌库成长解决“我接下来会遇到什么级别的机会与风险”。三条线需要互相绑定，避免成长只变成数值堆叠。

设计目标是让玩家感觉自己不是被动进入更难的明天，而是通过建筑和装备主动打开更危险、更有收益的明天，并逐步获得控制这些风险的能力。

我正在设计一个 Godot 4.6 俯视角 2D 游戏，请按专业游戏设计师角度直接分析，不要情绪安抚；如果设计不合理，需要直接指出。

项目当前不是传统开放生存，也不确定继续做纯肉鸽。最新判断是：这个玩法更适合向“堆叠大陆式卡牌经营生存 + 明日翻牌 + 短地图执行”方向收敛，而不是做《饥荒》式开放世界生存，也不是做 Brotato / Vampire Survivors 式动作肉鸽。

核心概念仍是 ERS / 明日构筑：玩家不是自然进入明天，而是通过某种系统获得、租用、翻开或改造明天。当前更倾向“翻牌”而不是“自由合成地图”。每天营地阶段出现一排盖着的明日牌，例如 5 张，牌类型包括地图牌、收益牌、风险牌、规则牌。玩家至少需要翻出 1 张地图牌才能生成明日地图；翻出地图后可以停止，也可以继续翻牌追加收益或风险。核心心流是“现在这个明天够不够好，要不要再翻一张”。

需要避免的方向：
- 不要做复杂自由地图合成。自由槽位太多会导致选择困难，像为了合成而合成。
- 不要让玩家完全自己设计挑战。更好的方法是系统出题，玩家有限干预或顺势应对。
- 不要把局内玩法做成复杂动作游戏。地图执行应短、明确、有反馈。
- 不要让所有压力源分散成多个失败条件。最终失败应统一表达为“没有明天 / 明日断供 / 明日违约”。

当前较合理的结构：
- 营地阶段是主要策略界面，接近《堆叠大陆》的卡牌、资源、结算、任务、设施体验。
- 地图阶段是短回合执行，用于兑现翻牌结果、环境联动和撤离压力。
- 翻牌系统提供随机性和风险收益；玩家后续可通过工具、设施或材料获得有限控制能力，例如查看一张盖牌、锁定一张牌、移除一张风险牌、诱导某类牌出现。
- 成长方式仍待定。可以保留合成，但合成重点应从大量武器防具转向：翻牌工具、环境应对装备、营地设施、ERS 控制工具。也可以考虑不用合成，改为商店购买、训练升级、蓝图/许可证解锁。
- 如果采用合成，材料不宜过于具体。基础材料可以具体，核心构筑材料更适合抽象成“元素核心”，例如回波、灰烬、浓雾、巢穴、停电、腐化。

玩家希望的关键爽点是“系统性策略成功 / 环境连锁收益”：
- 例如玩家通过某种方式达成“雷雨天 + 大片树木林 + 导电条件”，让雷击帮玩家自动伐木。
- 或者玩家把 Boss 引到火山地带，让岩浆烫死 Boss。
这说明 ERS 不应该只是给资源加成，而应该让玩家制造可利用的环境局面。推荐设计为：有限干预明天 -> 制造环境力 -> 进图执行条件 -> 触发系统连锁 -> 获得高收益或反杀 -> 承担代价。

当前正在讨论的问题：
1. 明日翻牌是否比自由合成更适合项目。
2. 如果做成中长线卡牌经营生存，合成系统该保留到什么程度。
3. 玩家角色在短地图中的具体交互要如何设计，避免地图阶段变成跑点拿奖励。
4. 失败条件如何统一成“没有明天”，同时保证有足够挑战。
5. 如何让翻牌、饱食度、租约/账单、末日压力、装备/设施成长形成清晰闭环。
